# Background Tab Stream Pre-fetcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automatically capture and enqueue next-episode streams into VLC from anime streaming sites that yt-dlp does not support, by briefly pre-fetching the next episode page in a silent, muted background tab and capturing its real CDN stream via the existing network sniffer before closing the tab.

**Architecture:** When the primary episode launches successfully in VLC, the background extension script (`extension/background.js`) opens a muted, non-active background tab for `nextEpisode.url`. The existing webRequest sniffer (`tracker.recordResponse`) intercepts the master playlist or direct video URL generated by the page's video player. As soon as the stream is captured (or upon a 15-second timeout), the background tab is closed and the extracted direct stream is sent to VLC via native messaging with `enqueue: true` and `is_direct: true`. If pre-fetching times out, it gracefully falls back to the local `yt-dlp` resolver.

**Tech Stack:** JavaScript (WebExtensions Manifest V3), Firefox tabs API (`browser.tabs.create`, `browser.tabs.update`, `browser.tabs.remove`), Python 3 stdlib, VLC CLI.

**Spec:** User request to pre-fetch the next episode stream in the background so that multi-episode anime on custom player sites (e.g. Kuramanime) automatically enter the VLC playlist without manual navigation.

## Review Focus

1. Silent execution: background tab is created with `active: false` and muted immediately so the user experience is undisturbed.
2. Guaranteed cleanup: `finally` block or hard timeout guarantees `browser.tabs.remove(tabId)` is called so background tabs never leak.
3. Event-driven capture: resolves as soon as `tracker.recordResponse` catches the stream, without waiting for the full 15s timeout.
4. Fallback resilience: if a site requires interactive captcha or blocks background loading, pre-fetcher times out cleanly and falls back to yt-dlp / notification without throwing uncaught exceptions.
5. Concurrent triggers: only one pre-fetch tab runs at any given time to avoid resource exhaustion.

   ```javascript
   if (recorded && details.tabId >= 0) {
     const resolver = tabStreamResolvers.get(details.tabId);

     }

   ```
2. `prefetchNextEpisodeStream(nextEpisodeUrl, timeoutMs = 15000)`:
   - Create tab:
     `const tab = await browser.tabs.create({ url: nextEpisodeUrl, active: false });`
   - Mute tab:
     `await browser.tabs.update(tab.id, { muted: true }).catch(() => {});`
   - Check if stream already caught:
     `const existing = tracker.getBestStream(tab.id);`
     `if (existing) return existing;`
   - Wait for stream with hard timeout:
     Create Promise tied to `tabStreamResolvers.set(tab.id, resolve)` and `setTimeout`:
     ```javascript
     const streamPromise = new Promise((resolve) => {
       tabStreamResolvers.set(tab.id, resolve);
     });
     const timeoutPromise = new Promise((resolve) => setTimeout(() => resolve(null), timeoutMs));
     ```
   - On tab complete status, lightly trigger play in case autoplay was blocked:
     ```javascript
     const onUpdatedListener = (tabId, changeInfo) => {
       if (tabId === tab.id && changeInfo.status === "complete") {
         browser.scripting.executeScript({
           target: { tabId },
           func: () => {
             const v = document.querySelector("video");
             if (v) v.play().catch(() => {});
           }
         }).catch(() => {});
       }
     };
     browser.tabs.onUpdated.addListener(onUpdatedListener);
     ```
   - In `finally`:
     - Clean up listener: `browser.tabs.onUpdated.removeListener(onUpdatedListener);`
     - Remove resolver: `tabStreamResolvers.delete(tab.id);`
     - Close tab: `await browser.tabs.remove(tab.id).catch(() => {});`
     - Clean tracker: `tracker.cleanupTab(tab.id);`

- [ ] **Step 3: Integrate with `handleVlcTrigger` in `extension/background.js`**

Update the next episode handling:
```javascript
if (meta.nextEpisode && meta.nextEpisode.url) {
  notify("VLC Opener", "Pre-fetching Episode " + meta.nextEpisode.number + " in background...");
  const captured = await prefetchNextEpisodeStream(meta.nextEpisode.url, 15000);
  if (captured && captured.url) {
    const queueRes = await sendUrlToVlc(captured.url, captured.referer || meta.nextEpisode.url, true, true);
    if (queueRes?.ok) {
      notify("VLC Opener", "Enqueued Episode " + meta.nextEpisode.number + " into VLC playlist.");
    }
  } else {
    notify("VLC Opener", "Resolving Episode " + meta.nextEpisode.number + " via yt-dlp fallback...");
    const queueRes = await sendUrlToVlc(meta.nextEpisode.url, tab.url, false, true);
    if (queueRes?.ok) {
      notify("VLC Opener", "Enqueued Episode " + meta.nextEpisode.number + " into VLC playlist.");
    }
  }
}
```
