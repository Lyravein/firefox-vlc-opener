# Background Tab Stream Pre-fetcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automatically capture and enqueue next-episode streams into VLC from anime streaming sites that yt-dlp does not support, by briefly pre-fetching the next episode page in a silent, muted background tab and capturing its real CDN stream via the existing network sniffer before closing the tab.

**Architecture:** When the primary episode launches successfully in VLC, the background extension script (`extension/background.js`) manages a single-flight background tab for `nextEpisode.url`. The existing webRequest sniffer (`tracker.recordResponse`) intercepts the master playlist or direct video URL generated by the page's video player across top frames and embedded iframes. As soon as the stream is captured (or on tab removal / 15-second timeout), the background tab is closed and the extracted direct stream is sent to VLC via native messaging with `enqueue: true` and `is_direct: true`. If pre-fetching times out, it gracefully falls back to the local `yt-dlp` resolver.

**Tech Stack:** JavaScript (WebExtensions Manifest V3), Firefox tabs API (`browser.tabs.create`, `browser.tabs.update`, `browser.tabs.remove`), Python 3 stdlib, VLC CLI, Node.js.

**Spec:** User request to pre-fetch the next episode stream in the background so that multi-episode anime on custom player sites (e.g. Kuramanime) automatically enter the VLC playlist without manual navigation.

- Muted background tab: the pre-fetch tab must be created with `active: false` and set to `muted: true` so it never plays audio or steals focus from the user.
- Single-flight concurrency: only one pre-fetch tab runs at any time; overlapping requests are ignored or cancel the prior job.
- Backward compatibility: single-episode playback and standalone context menu actions must continue working untouched.

## Review Focus

1. Silent execution: background tab is created with `active: false` and muted immediately so the user experience is undisturbed.
2. Guaranteed cleanup: `finally` block or hard timeout guarantees `browser.tabs.remove(tabId)` is called, listeners are detached, and `clearTimeout` runs so background tabs and timers never leak.
3. Event-driven capture: resolves as soon as `tracker.recordResponse` catches the stream, without waiting for the full 15s timeout.
4. Sub-frame player interaction: `browser.scripting.executeScript` specifies `allFrames: true` so iframe video players receive play triggers.
5. Early close handling: if tab is removed early, pre-fetch resolves `null` immediately without hanging for 15s.

- [ ] **Step 3: Implement pre-fetcher in `extension/background.js`**

1. Add single-flight guard:
   ```javascript
   let activePrefetchJob = null;
   ```
2. Add stream resolver map:
   ```javascript
   const tabStreamResolvers = new Map();
   ```
3. In `browser.webRequest.onHeadersReceived`:
   When `recorded && details.tabId >= 0`:
   ```javascript
   const resolver = tabStreamResolvers.get(details.tabId);
   if (resolver) {
     tabStreamResolvers.delete(details.tabId);
     resolver(tracker.getBestStream(details.tabId));
   }
   ```
4. Implement `prefetchNextEpisodeStream(nextEpisodeUrl, timeoutMs = 15000)`:
   - If `activePrefetchJob`, return `null`.
   - Set `activePrefetchJob = nextEpisodeUrl;`
   - Create tab:
     `const tab = await browser.tabs.create({ url: nextEpisodeUrl, active: false });`
     `await browser.tabs.update(tab.id, { muted: true }).catch(() => {});`
   - Set up listener for `onUpdated` with `allFrames: true` on `complete`:
     ```javascript
     const onUpdatedListener = (tabId, changeInfo) => {
       if (tabId === tab.id && changeInfo.status === "complete") {
         browser.scripting.executeScript({
           target: { tabId, allFrames: true },
           func: () => {
             const v = document.querySelector("video");
             if (v) v.play().catch(() => {});
             const btn = document.querySelector(".play-button, [aria-label*='play' i], .vjs-big-play-button");
             if (btn) btn.click();
           }
         }).catch(() => {});
       }
     };
     browser.tabs.onUpdated.addListener(onUpdatedListener);
     ```
   - Set up listener for early `onRemoved`:
     ```javascript
     const onRemovedListener = (tabId) => {
       if (tabId === tab.id) {
         const r = tabStreamResolvers.get(tab.id);
         if (r) {
           tabStreamResolvers.delete(tab.id);
           r(null);
         }
       }
     };
     browser.tabs.onRemoved.addListener(onRemovedListener);
     ```
   - Race between stream Promise and `setTimeout`:
     ```javascript
     let timer = null;
     const timeoutPromise = new Promise((resolve) => {
       timer = setTimeout(() => {
         tabStreamResolvers.delete(tab.id);
         resolve(null);
       }, timeoutMs);
     });
     const streamPromise = new Promise((resolve) => {
       tabStreamResolvers.set(tab.id, resolve);
     });
     const stream = await Promise.race([streamPromise, timeoutPromise]);
     clearTimeout(timer);
     ```
   - In `finally`:
     - Clean listeners:
       `browser.tabs.onUpdated.removeListener(onUpdatedListener);`
       `browser.tabs.onRemoved.removeListener(onRemovedListener);`
     - Remove tab:
       `await browser.tabs.remove(tab.id).catch(() => {});`
     - Clean tracker:
       `tracker.cleanupTab(tab.id);`
     - Reset mutex: `activePrefetchJob = null;`
5. Integrate with `handleVlcTrigger(tab, meta = {})`:
   - If `meta.nextEpisode && meta.nextEpisode.url`:
     - `notify("VLC Opener", "Pre-fetching Episode " + meta.nextEpisode.number + " in background...");`
     - `const captured = await prefetchNextEpisodeStream(meta.nextEpisode.url, 15000);`
     - If `captured && captured.url`:
       - `const queueRes = await sendUrlToVlc(captured.url, captured.referer || meta.nextEpisode.url, true, true);`
       - If `queueRes?.ok`: `notify("VLC Opener", "Enqueued Episode " + meta.nextEpisode.number + " into VLC playlist.");`
     - Else:
       - Fallback to `sendUrlToVlc(meta.nextEpisode.url, tab.url, false, true)` (yt-dlp).
